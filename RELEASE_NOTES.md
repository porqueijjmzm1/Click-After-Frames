## What's new in v3.6.0

- **iOS support!** Kosmos now runs on iPhone and iPad with the Geode launcher. See the [install steps](https://porqueijjmzm1.github.io/Kosmos/#install) for how to add the file.
- **Intel Macs** are supported too: the macOS build now runs on both Apple silicon and Intel.
- **New website**: [porqueijjmzm1.github.io/Kosmos](https://porqueijjmzm1.github.io/Kosmos/), with the download, a live copy of the menu, every theme, install steps for each platform and every setting explained. It's also the mod's homepage link in Geode.
- **New home on GitHub**: the project moved to [github.com/porqueijjmzm1/Kosmos](https://github.com/porqueijjmzm1/Kosmos). Old links still work, and updates keep coming the same way.

## Install

Put Kosmos.geode in your Geode mods folder and remove older copies (InputBuffer.geode, TESTEBUFFER.geode or basu.input-buffer.geode), or both run at once. On iOS, upload it with the Geode launcher's web upload (see the website).

Based on Click Before Frames by BASU.
